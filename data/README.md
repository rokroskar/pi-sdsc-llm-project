# Data Directory

This directory contains cached data files.

## Zurich Water Fountain Dataset

Source: [Open Data Zürich - Brunnen (Water Fountains)](https://data.stadt-zuerich.ch/dataset/geo_brunnen)

The dataset is downloaded automatically on first run via the CKAN API.
Primary endpoint: `https://data.stadt-zuerich.ch/api/3/action/package_show?id=geo_brunnen`
